## Outcome

Protocol 1.0.1 replaces dynamic-response reference hashes with exact repository bytes under `artifacts/evidence/rcl-205/`. The manifest binds ten permitted captures by relative path, exact byte count, SHA-256, retrieval timestamp, semantic anchor, media type, transformation, and redistribution boundary.

The verifier requires no network access and rejects path escape, missing files, byte drift, hash drift, malformed provenance, disallowed source hosts, chronology mismatches, incorrect publication-to-GEO linkage, and an incorrect or non-unique exact XLSX row.

## Failure history retained

- The first test-file patch failed because its parent directory did not yet exist.
- Direct script execution was blocked by the machine's execution policy; all evidence commands use process-scoped `-ExecutionPolicy Bypass` and do not change machine policy.
- The first verifier run evaluated `$PSScriptRoot` too early in a parameter default and was corrected for Windows PowerShell 5.1.
- The first mutation run reported a downstream JSON parser error after already detecting hash drift; corrupted captures are now excluded from semantic parsing so the verifier emits the typed integrity failure.
- The first XLSX integration used a missing dynamic XML property under StrictMode; it now uses explicit attribute access.
- One compressed review command failed before execution because of malformed `foreach` spacing and was rerun readably.

The canonical error IDs and resolutions are retained in `docs/project/ERROR_LOG.md`.
