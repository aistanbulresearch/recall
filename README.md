# Recall

Recall helps clinical genetics teams revisit previously uncertain results when public evidence changes.

Instead of asking specialists to repeatedly reopen every historical case, Recall monitors approved public sources, constructs an auditable evidence delta, independently verifies material claims and citations, and creates a review task only when deterministic policy permits it.

Recall does not autonomously classify variants, change clinical reports, or contact patients. The clinician remains the final authority.
