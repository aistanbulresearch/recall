## Capture requirements

- exact commit and deployed revision;
- exact run ID;
- atomic data modes, run `mode_set`, and declared composition;
- source artifact hashes;
- screen recording or screenshot path;
- criterion supported;
- known limitations;
- confirmation that displayed values were derived, not entered manually.
- confirmation that every non-live data mode is explicit in the captured frame;
- deployed revision, run and trace identifiers, modes, artifact hashes, terminal state, task count, activation counters, and latency, whether or not the owner approves the proposed `RunEvidenceManifest` packaging;
- exact numerators, denominators, and Wilson 95% confidence intervals for any admitted scale funnel;
- explicit acceleration labeling for any admitted Week 0/3/6 sequence.
